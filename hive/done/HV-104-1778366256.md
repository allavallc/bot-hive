## Goal

Make every bot's terminal visually identify itself so the human can tell sessions apart at a glance. Two mechanisms:

1. **Windows Terminal tab title** — set via `wt.exe --title "<colony>.<handle>"` at spawn time. Shows in the tab bar.
2. **Claude Code statusline** — write `.claude/settings.json` in each worktree with a `statusLine` command that reads `.bot-hive-identity` and prints `<colony>.<handle>` (and later, the bot's role once FS-023 ships) at the bottom of the chat, persistent across every interaction.

## Notes

The Claude Code `statusLine` setting takes a command (or path to a script) that prints text. The harness re-runs the command periodically. Keep the script fast (sub-100ms) — `cat .bot-hive-identity | grep ...` is plenty.

Per ADR-003 ".bot-hive-identity" + colony-aware AGENTS.md additions, this slots right into the existing identity flow. No new identity concepts needed.

The orchestrator's main checkout (where the human + I work together) should also get a `.claude/settings.json` for parity — printing something like `orchestrator (allavallc) · main`. Cover that in the same PR if scope-creep allows; if not, file as a follow-up.
