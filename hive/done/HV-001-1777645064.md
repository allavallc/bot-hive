## Goal
Stand up an empty Next.js (App Router, TS) project wired to local Postgres via Drizzle, with the `.env` contract in place.

## Why
Every later ticket assumes a working dev loop and a typed DB client. Building this once means later tickets start green.

## Done when
- `package.json`, `tsconfig.json`, `next.config.ts`, `drizzle.config.ts` exist and resolve correctly.
- `.env.example` lists every var the app reads.
- `npm run dev` serves the default page on `localhost:3000`.
- `npm run db:migrate` connects to Postgres and exits 0 (no migrations yet).
- `tsc --noEmit` and `eslint` pass.

## Desired output
Fresh clone → fill `.env` → `npm install && npm run dev` → default page in ≤1 min.

## Success signals
- `psql "$DATABASE_URL" -c "SELECT 1"` connects.
- `tsc` and `eslint` are green from day one.

## Failure signals
- DB connection eagerly opened at import (errors on missing env).
- `.env.example` drifts from what code actually reads.

## Tests
- Manual: clone fresh, run dev, hit `localhost:3000`.
- Manual: `npm run db:migrate` against an empty database.

## Notes
- Postgres is native (no Docker). Default URL: `postgresql://postgres:<password>@localhost:5432/bot_hive`.
- Schema, auth, GitHub, board are HV-002…HV-007.

## Resolution
- Stack landed: Next.js 15.5.15 + React 19 + TS 5.6 + Drizzle 0.36 + postgres 3.4 + Biome 1.9.
- Added `dotenv` (devDep) so `drizzle-kit` reads `.env`. Not in original spec but needed to make `db:migrate` work without shell wrappers.
- `drizzle-kit migrate` requires `drizzle/meta/_journal.json` even when there are no migrations. Bootstrapped an empty journal (`{"version":"7","dialect":"postgresql","entries":[]}`) so the wiring verifies clean. The journal will be regenerated naturally when HV-002 runs `drizzle-kit generate`.
- Verified: `tsc --noEmit` ✓, `biome check` ✓ (8 files), `db:migrate` ✓ (connects, no-op against empty journal), dev server boots Next 15 in 7.5s and serves `/` with the expected page (200).
- 7 npm-audit vulnerabilities reported (6 moderate, 1 high). Tracking — not addressed in this ticket; revisit if any fall in the runtime path.
