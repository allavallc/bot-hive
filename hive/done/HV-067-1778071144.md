## Goal
Scrub `hive/HIVE.md` of prose that hardcodes "Claude" / "Claude Code" as the only kind of agent. The format spec must read identically to a Codex / GPT / Aider / Gemini agent. Examples flagged by the 2026-05-06 audit:

- Line 388: "Two **Claude Code** sessions on the same laptop get different handles." → "Two agent sessions on the same laptop..."
- Line 424: "each **Claude session** is a fresh entity in the swarm." → "each agent session..."

## Why
The split between `AGENTS.md` (any agent) and `CLAUDE.md` (Claude shim) was created so non-Claude agents read the right file. But `HIVE.md` is the *format* spec — supposed to be agent-neutral by definition — and it still narrates as if Claude is the audience in places. A Codex session reading "Two Claude Code sessions on the same laptop" has to mentally translate; a future Aider session might not bother.

## Done when
- The two flagged lines (and any sibling phrasings the implementer notices during the read) are reworded to "agent session" / "LLM session" / "bot session" — whichever fits the local sentence.
- A grep run after the edit confirms `Claude Code` and `Claude session` no longer appear in `hive/HIVE.md` (model identifiers in examples like `claude-opus-4-7` are *kept* — the slot is generic, the example value is illustrative).
