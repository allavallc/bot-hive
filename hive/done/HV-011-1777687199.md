## Goal
After Bot Hive sign-out, show a one-line hint linking to `https://github.com/logout` for users on shared machines.

## Why
HV-003's grant-revoke closes silent re-auth, but a coworker clicking "Sign in with GitHub" can still see *whose* account is about to be authorized — and click through if they're malicious. Telling the user "also sign out of GitHub" is the only end-to-end fix on shared computers, and it has to be the user's deliberate action since we can't force a third-party logout.

## Done when
- Sign-out lands on `/login` with a banner or paragraph: *"You've been signed out of Bot Hive. On a shared computer? [Also sign out of GitHub](https://github.com/logout)."*
- Hint dismissable via a "got it" button that sets a localStorage flag; future sign-outs hide it.
- Link opens in a new tab so we don't lose the user's place.

## Desired output
After clicking sign-out, the user sees a hint they can act on or dismiss. No flow change for the "I'm on my own laptop" majority case after they dismiss once.

## Success signals
- Banner copy is clear at a glance (no jargon).
- Dismiss state survives page reload.

## Failure signals
- Banner shown on every sign-out forever (annoying — defeats dismissibility).
- Link to GitHub logout breaks (GitHub renames the URL).

## Tests
- Manual: sign out → banner appears → click GitHub logout link → opens new tab to github.com/logout.
- Manual: dismiss → sign out again → banner gone.

## How to test
1. Sign in.
2. Sign out — observe the banner on `/login`.
3. Click "Also sign out of GitHub" — confirm new tab opens to `https://github.com/logout`.
4. Click the dismiss button.
5. Sign in again, sign out again — banner should not appear.
6. Clear localStorage → sign out → banner reappears.

## Notes
- Blocked by HV-007 because the styled `/login` page lands there; doing this on the placeholder unstyled page is wasted work.
- Out of scope: forcing GitHub logout (impossible without GitHub's cooperation), email reminders, "are you on a shared computer?" toggle on sign-in.

## Resolution
- Single file: `src/app/login/page.tsx` — added `useState` + `useEffect` to read `localStorage["bot-hive:signout-hint-dismissed"]` and conditionally render an `<aside>` banner with the GitHub logout link (target=_blank, rel=noopener noreferrer) plus a "Got it" button that writes the dismiss key.
- Banner styling lands later via HV-013's shared `ui.hint` class — currently uses the design system primitives (`ui.btnGhost`, `ui.hint`) introduced in HV-013.
- Banner shows on every `/login` visit until dismissed (one permanent dismissal). Simpler than tracking just-signed-out transient state; matches the "show until they say got it" UX expectation.
