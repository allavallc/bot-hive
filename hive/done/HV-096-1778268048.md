## Goal
A bot whose handle is the `Owner:` of FS-019 (or any FS that designates the tester) DAG-walks `hive/in-review/` instead of `hive/backlog/`. It picks the oldest in-review ticket not already reviewed by it, runs the rubric, approves or rejects.

## Done when
- `scripts/my-work.sh` and `.ps1` detect "I am a tester" by reading owned FS list — if any owned FS has `Role: tester` (new field), surface in-review tickets as the work queue
- Tester's available work = `in-review/*.md` filtered to: not yet reviewed by this tester, no soft-fence claim from peer tester
- Coder bots ignore tester-owned FSs in their DAG-walk (already handled by Owner field)

## Notes
- Add `**Role**:` to FS frontmatter. Vocabulary: `coder` (default), `tester`, `pm`. Empty = `coder`.
- Tester's "claim" is short — read PR, run tests, post approve/reject. No Git mutations beyond the reject-PR or approve-PR.
