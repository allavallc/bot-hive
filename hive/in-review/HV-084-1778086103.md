## Goal
Remove "Generated <datetime>" from the masthead and place it right-aligned in the crumb row, flush with "← Dashboard" on the left — so it reads as board metadata rather than part of the persistent site header.

## Why
The timestamp is board-specific metadata, not a site-level UI element. In the masthead it sits alongside the "● live" indicator but visually competes with the wordmark. Moving it to the crumb row puts it closer to the board content it describes, and the left/right split (← Dashboard | Generated ...) gives both items clear visual ownership of their side.

## Done when

### JSX change (`board.client.tsx`)
- Remove `<span className={styles.generatedAt}>` from `<div className={styles.mastheadMeta}>`.
- Wrap the crumb `<nav>` and a new `<span className={styles.generatedAt}>` in a flex row:

```tsx
<div className={styles.crumbRow}>
  <nav className={styles.crumb}>
    <a href="/dashboard" className={styles.crumbLink}>← Dashboard</a>
  </nav>
  <span className={styles.generatedAt}>Generated {generatedAt.toLocaleString()}</span>
</div>
```

### CSS change (`board.module.css`)
- Add `.crumbRow`: `display: flex; justify-content: space-between; align-items: baseline; margin-bottom: 12px;`
- Remove `margin-bottom` from `.crumb` (it moves to `.crumbRow`).
- `.generatedAt` needs no change — existing dimmed style carries over.

### "● live" indicator
Stays in the masthead — it's a connection-state signal, not board metadata.

## How to test
Open the live board. Confirm:
- No timestamp in the masthead.
- "← Dashboard" on the left and "Generated <datetime>" on the right, same baseline, above the Board/repo subnav row.
- "● live" / "○ reconnecting" still visible in the masthead.
- Layout holds at narrow viewport (no wrapping issues).
