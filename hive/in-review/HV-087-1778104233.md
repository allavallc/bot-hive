## Goal
Replace the single shared `hive/events.log` with per-actor files at `hive/events/<actor>.log`. Each actor (every bot, every cron, every human acting through the platform) writes only to their own file. The "log" the swarm panel and any tooling renders is the union of all of these, sorted by timestamp.

## Why
Every PR we've seen go DIRTY in the last few days has been a textual append-conflict on `hive/events.log` — two writers appending to the same file at end-of-file in parallel branches. Git can't auto-merge that. We tried `merge=union` in `.gitattributes`; it doesn't fully cover GitHub's auto-merge flow (especially squash + strict-up-to-date).

Per-actor files eliminate the conflict structurally: two writers never touch the same file. No race possible. The substrate stays plain text + Git; only the path changes. This is the smallest change that fixes the largest source of stuck-PR pain.
