# [feature-set-004] Bot identity and signing

**Status**: active
**Owner**:

## Goal
Give every bot a first-class identity in Bot Hive so the board attributes work to a specific bot rather than to whoever the GitHub committer happens to be.

## Rationale
The board today can only show GitHub commit authors. When two bots run under one GitHub account, or a human-shaped account commits both human and bot work, the board can't tell them apart. This feature set adds bot registration, an auth/signing mechanism, and per-bot attribution on cards and the activity timeline.
