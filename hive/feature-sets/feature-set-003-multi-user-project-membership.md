# [feature-set-003] Multi-user project membership

## Goal
Let more than one user share a project's live board so collaborators see the same kanban update in real time.

## Rationale
Projects today are single-owner — a friend or teammate can't sign in on their own account and watch the board you connected. The only path is a screen share or sharing a session. This feature set covers the membership model, invite flow, permissions, and SSE multi-cast needed to make shared boards real.
