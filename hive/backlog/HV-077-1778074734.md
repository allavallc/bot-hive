## Goal
Stop rendering the Effort badge (XS / S / M / L / XL) on board cards. The field stays in the ticket markdown and the detail panel — only the card-level badge is removed.

## Why
The Effort sizing is PM/planning metadata, not something a human glancing at the board needs per-card. It adds visual noise to the `cardTop` row (already carrying the ticket ID and Priority badge) without providing actionable signal at a glance.

## Done when
- The `{fm.Effort && <span ...>{fm.Effort}</span>}` render in the `Card` component (`board.client.tsx`) is removed.
- The `Effort` field in ticket markdown files is untouched.
- The Effort value remains visible in the ticket detail panel (rendered from `metaEntries` — no change needed there).
- typecheck + lint + build clean.

## How to test
Open the live board. Confirm no XS / S / M / L / XL badge appears on any card. Open a ticket detail panel — Effort is still visible in the metadata list.

## Notes
- One-line deletion in `board.client.tsx`. No CSS changes needed (`.badge` class is shared with Priority; removing the element is sufficient).
- Out of scope: removing Effort from the detail panel or from ticket markdown.
