## Goal
Let a signed-in user install Hive on a repo and see its `hive/` folder synced into the DB.

## Why
This is the first end-to-end loop: identity → installation → project row → tickets in DB. Without it the board has nothing to render.

## Done when
- `/projects/new` shows an "Install Hive on a repo" button linking to the GitHub App install URL.
- `/projects/install/callback` handles `?installation_id=X&setup_action=install`, writes a `projects` row, kicks off `initialSync(projectId)`, redirects to `/projects/[id]`.
- `src/lib/sync.ts` exposes `initialSync(projectId)`: list `hive/` via Contents API, parse each file, upsert into `tickets` and `features`, set `last_sync_sha` to repo HEAD.
- `src/lib/parse.ts` exposes pure `parseTicket(content)` and `parseFeatureSet(content)` reusing bot-horde field/section names verbatim.

## Desired output
Install Hive on a fixture repo with 3 backlog + 1 in-progress + 1 feature-set → click Connect → within 30s, rows appear in `tickets`/`features` with `sync_state.last_sha` matching HEAD.

## Success signals
- Re-running `initialSync` is idempotent: same input → same DB state, no duplicate rows.
- Parser tolerates legacy/missing optional fields (matches bot-horde validator behavior).

## Failure signals
- Partial sync leaves `last_sha` ahead of actual data on transient API failure.
- Frontmatter parse errors crash the whole sync instead of skipping the bad file with a warning.
- Files outside `hive/` end up parsed (path filter wrong).

## Tests
- Manual: connect a fixture repo, inspect rows.
- Unit: `parseTicket` round-trips canonical bot-horde tickets (use copies from `bot-horde/done/`).
- Unit: `parseTicket` on a file missing `Desired output`/`Success signals` returns a ticket without those fields, no throw.
- Unit: `initialSync` called twice in a row produces zero diff after the second call.

## Notes
- Initial-sync runs in-band on the install callback; if it grows past a few seconds we move it to a background job — not now.
- Fixture repo prep: 3 tickets in `hive/backlog/`, 1 in `hive/in-progress/`, 1 feature-set in `hive/feature-sets/`.
- Out of scope: deletion / disconnect flow.
