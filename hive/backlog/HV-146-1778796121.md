## What

Remove the `add coder` and `add tester` subcommands from `scripts/hive.ps1` and `scripts/hive.sh`. Keep `stop`.

## Why

In the new design, every bot starts with `start the hive` in a new terminal. The server assigns the role. There is no "spawn a coder" vs "spawn a tester" distinction at the script level — the script was serving the old design where the operator pre-labeled the role.

## Done when

- `.\scripts\hive.ps1 add coder` and `add tester` print a clear deprecation message: "Role assignment is now server-side. Open a new terminal and type `start the hive` — the server will assign the correct role."
- `.\scripts\hive.ps1 stop` still works as before.
- `.\scripts\hive.sh` matches.
- Help text updated.

## Note

Don't silently break `add coder`/`add tester` — print a clear message so any operator with old muscle memory gets a useful error, not a crash.
