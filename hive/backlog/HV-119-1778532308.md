## Goal

Verify the existing Mac and Linux variants of Add-a-Bot Step 1 actually work end-to-end before any non-Windows user is invited to use Bot Hive.

## What to do

- Spawn a bot via Add-a-Bot on a Mac with Terminal.app. Confirm `worktrees/<handle>/.bot-hive-identity` is well-formed JSON (or correct format for the file), `osascript` opens a new tab in the right directory, bot starts cleanly.
- Repeat on a Linux machine (any terminal). Confirm the manual fallback note is clear; identity file lands; bot starts.
- Document any breakage as separate fix tickets.

## Done when

- [ ] One successful Mac spawn end-to-end (identity → terminal → Claude Code → bot-startup → claim a dummy ticket)
- [ ] One successful Linux spawn end-to-end (same chain)
- [ ] Any breakage filed as a separate ticket against the relevant platform variant
- [ ] Note added to FS-014 confirming Mac/Linux are launch-ready (or listing the open blockers)
