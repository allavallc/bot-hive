## Goal

Fix z-index / positioning conflict between the fixed "+ Add a bot" button and the accept/reject side panel. Today the button overlaps the panel's close control, blocking the human from dismissing the panel.

## Likely cause

The "+ Add a bot" button (added in HV-100) is fixed-positioned top-right with a high z-index. The accept/reject panel uses similar positioning. The two stack on top of each other in the same corner.

## Done when

- [ ] With the accept/reject panel open, the close button (X / Escape target) is reachable and clickable
- [ ] "+ Add a bot" button still visible and clickable when no panel is open
- [ ] No regression in panel render quality

## Implementation notes (suggestion only — visual approval required before coding)

Two simple paths, pick one with the human:
1. Hide the "+ Add a bot" button while the accept/reject panel is open (cleaner — one button at a time).
2. Move the "+ Add a bot" button to a non-overlapping position (e.g. top-left or bottom-right).

Wait for explicit visual approval on placement before writing code per the project's UI change rule.
