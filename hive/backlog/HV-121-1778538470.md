## Goal

Remove or migrate legacy bare-handle data so the corresponding invariants stop firing.

## Concrete changes

- **Audit `hive/events/`** — list every `*.log` file whose name doesn't follow `<colony>.<handle>.log`. Today: `allavallc-cc1.log`, `allavallc.log` (the human's own). Decide per file:
  - `allavallc-cc1.log` — historical bot from a prior naming convention. Rename to `allavallc.cc1.log` (qualified) OR archive to `hive/events/_archive/` and exclude from the cron's scan.
  - `allavallc.log` — the human's actor log. Doesn't fit the bot-naming scheme but is intentional. Either rename to `allavallc.allavallc.log` (treat human as a colony bot for protocol consistency) OR add a one-off exception in the EVENT_LOG_BARE_HANDLE invariant for human-actor logs.
- **Audit `hive/feature-sets/*.md`** — find any `Owner: <bare-handle>` (e.g. `Owner: allavallc-cc1`). Migrate to colony name (per ADR-003 the Owner field is now a colony, not a bot handle).
- **Audit `hive/in-review/`** — confirm HV-114 covers the `Assigned to:` field cleanup; if not, sweep here too.
