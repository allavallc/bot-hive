## Goal
Peer `your-role` push events currently carry `skillFiles: []` and no `departed` handle. Fix both so surviving bots know which files to load and who left.

## Why
`roleForSeat()` already computes `skillFiles` for each bot's new role. `PeerPush` drops them before the event goes out. `disconnectBot()` knows the departing handle but doesn't pass it to peers.

## Changes
- `src/lib/bot-stream.ts`: add `skillFiles: string[]` and `departed: string` to `PeerPush` type; populate both in `connectBot` and `disconnectBot` peer-push loops
- `src/lib/bot-notify.ts`: pass `p.skillFiles` and `p.departed` instead of `[]` / omitting

## Done when
- `your-role` events received by surviving bots have non-empty `skillFiles` after a peer disconnects
- `your-role` events include the departed bot's handle
- Existing tests pass; typecheck clean
