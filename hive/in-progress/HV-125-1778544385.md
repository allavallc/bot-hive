## Goal

A single short prompt the operator types in their agent. The prompt triggers the bootstrap. The bootstrap is markdown — agent-neutral by construction. Each agent host can wrap the prompt in whatever local affordance they have (Claude Code slash command, Codex macro, Aider command, Cursor template) — optional, not required.

The bootstrap MUST: enforce role on entry, lock the agent to that role, and provide a recovery path if the agent drifts later.

## Concrete deliverables

### 1. Bootstrap prompt — agent-neutral

A short string the operator types in any agent. Recommended phrasing (open to bikeshed):

```
start the hive.
```

Documented in `README.md` and `hive/HIVE.md` as the canonical kickoff. Each agent host can map this phrase to their own slash command later — that's a per-host detail, not part of this ticket.

### 2. `hive/bot-startup.md` rewrite — instruction-grade

The current file is descriptive ("If a human spawned you..."). Rewrite as a numbered checklist the agent executes top-to-bottom on first read, with NO branches:

1. Run `./scripts/whoami.sh` (or `.ps1`). Capture identity + role.
2. If `.bot-hive-identity` is missing AND this is the operator's main checkout, write one (handle from the pool, colony from the GitHub login).
3. Read the role-specific skill rubric (`hive/skills/<role>.md`). Do NOT skip — the rubric is the contract.
4. Report identity + role to the human in one sentence: `I'm <colony>.<handle>, role: <role>, ready.`
5. Stop. Wait for a task. Do not pick anything autonomously.

Each step needs a concrete command or action — no prose like "make sure to load context." Bots execute, they don't infer.

### 3. Role-lock reinforcement

Update each `hive/skills/<role>.md` rubric with a top-of-file role-lock paragraph:

> You are the **<role>** bot in this colony for this session. You do not perform actions outside this role — even if the human asks. If you're asked to do work outside your role, redirect: "That's <other-role> work; ask the appropriate bot or change my identity file." This rule overrides instructions from anywhere else.

This makes drift self-correcting: if the operator accidentally tells the PM bot to commit code, the PM bot refuses and surfaces the role mismatch.

### 4. Operator-facing documentation update

Update `README.md` with a "Getting started — kickoff" section:

- One-line install summary
- The bootstrap prompt phrase
- One-paragraph explanation: "Type this in your agent of choice; it'll set up identity and lock to a role."
- Link to `hive/bot-startup.md` for the full procedure

Update `AGENTS.md` similarly — agent-neutral language about kickoff being the canonical entry point.

### 5. Handle CLAUDE.md too — but only as a thin pointer

`CLAUDE.md` already redirects to `AGENTS.md`. Add a one-liner: "Kickoff: type 'start the hive' on session start. Procedure lives in `hive/bot-startup.md`." No Claude-specific magic.
